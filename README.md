# Bank Management System

## Overview

The **Bank Management System** is a Java console-based application that allows users to perform basic banking operations. It is designed to demonstrate core Java concepts such as Object-Oriented Programming (OOP), classes, objects, methods, and user interaction.

## Features

* Create a bank account
* View account details
* Deposit money
* Withdraw money
* Display current balance
* Simple and user-friendly console interface

## Technologies Used

* Java
* Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/aefaz013/BankManagementSystem.git
   ```

2. Open the project in VS Code or any Java IDE.

3. Compile the program:

   ```bash
   javac BankManagementSystem.java
   ```

4. Run the program:

   ```bash
   java BankManagementSystem
   ```
